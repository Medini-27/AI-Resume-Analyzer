# AI Resume Analyzer

An AI Resume Analyzer built using Python and Flask. This project is designed to help users upload and analyze resumes through a simple web interface.

## Features

- Upload resumes
- Resume analysis
- Clean and simple user interface
- Flask-based web application

## Tech Stack

- Python
- Flask
- HTML
- CSS
- Git
- GitHub

## Installation

1. Clone the repository

git clone https://github.com/Medini-27/AI-Resume-Analyzer.git

2. Create a virtual environment

python -m venv .venv

3. Activate it

Windows:
.venv\Scripts\activate

4. Install dependencies

pip install -r requirements.txt

5. Run the project

python app.py
